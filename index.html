Kiểm tra Trạng thái Bản quyền Máy tính

Sao chép nhanh lệnh kiểm tra thời hạn bản quyền Windows hoặc Office hiện tại của bạn.

Trung tâm Kích hoạt Bản quyền Windows & Office

Chọn phương thức kích hoạt ưa thích hoặc sử dụng trình tạo file lệnh tùy chỉnh bên dưới.

Phương thức 1 Khuyên dùng (Online PS)

PowerShell (Truyền tải trực tiếp)

Lệnh tiêu chuẩn chạy trực tiếp qua PowerShell để mở menu MAS hoàn chỉnh từ get.activated.win.

irm https://get.activated.win | iex

Hướng dẫn thực hiện:

1. Nhấp chuột phải vào Start -> Chọn Terminal (Admin).

2. Dán lệnh trên vào cửa sổ PowerShell và nhấn Enter.

3. Chọn phím số tương ứng để hoàn tất kích hoạt.

File Batch độc quyền:
Phương thức 2 Mirror URL (Massgrave)

PowerShell (Massgrave Domain)

Đường dẫn thay thế chính thức từ domain gốc massgrave.dev đảm bảo tính ổn định cao.

irm https://massgrave.dev/get | iex

Hướng dẫn thực hiện:

1. Mở PowerShell với quyền quản trị viên.

2. Dán lệnh trên vào cửa sổ PowerShell và nhấn Enter.

3. Giao diện MAS sẽ khởi chạy, chọn cấu hình mong muốn.

File Batch độc quyền:
Phương thức 3 Command Prompt (CMD)

CMD Script & Curl Download

Sử dụng công cụ cURL có sẵn trên Windows để tải file kịch bản và tự động kích hoạt qua PowerShell.

curl -L https://get.activated.win -o .\activate.ps1; powershell .\activate.ps1

Hướng dẫn thực hiện:

1. Nhấn Windows, gõ cmd, chọn Run as administrator.

2. Dán lệnh cURL vào CMD và nhấn Enter.

3. Tập lệnh tự động xử lý cấu hình bản quyền Office/Windows.

File Batch độc quyền:
Phương thức 4 Slmgr / KMS Trực tiếp

VBScript Quản lý Bản quyền

Sử dụng công cụ quản lý giấy phép phần mềm gốc (Software Licensing Management Tool) trên Windows.

cscript slmgr.vbs /ato

Hướng dẫn thực hiện:

1. Mở Command Prompt (Admin).

2. Đổi KMS server nếu cần (vd: cscript slmgr.vbs /skms kms8.msguides.com).

3. Gõ lệnh trên và ấn Enter để kích hoạt.

File Batch độc quyền:

Trình tạo Custom Batch Script trực tiếp trên Web

Tự chọn loại kích hoạt phù hợp và tải xuống file lệnh riêng biệt được tối ưu hóa tự động.

Xem trước nội dung Script (.bat): 
@echo off
title MAS Custom Script - HWID Activation
powershell -Command "irm https://get.activated.win | iex"
pause

Khắc phục sự cố & Hỏi đáp (FAQ)

Tổng hợp cách xử lý các lỗi thường gặp trong quá trình kích hoạt.

Nguyên nhân do Windows Defender nhận diện nhầm các lệnh tự động hóa hệ thống. Đây là mã nguồn mở hoàn toàn minh bạch. Bạn chỉ cần tạm tắt Windows Security trong giây lát hoặc thêm ngoại lệ (Exclusion) cho file tải về trước khi chạy với quyền Administrator.

Lỗi 0x80070005 thường xuất hiện do bạn chưa chạy CMD/PowerShell dưới quyền Administrator. Hãy chắc chắn nhấp chuột phải chọn "Run as administrator". Đồng thời kiểm tra lại kết nối mạng Internet hoặc tường lửa công ty.

Không cần thiết. Đối với phương thức HWID (Digital License), bản quyền đã được lưu vĩnh viễn trên máy chủ Microsoft ngay cả khi bạn cài lại Windows. Các file batch do hệ thống tạo ra cũng tự động xóa sau khi chạy xong để đảm bảo bảo mật tuyệt đối.

Chào mừng đến với MAS Pro Ultimate

Công cụ hỗ trợ kích hoạt bản quyền chính thống sử dụng mã nguồn mở MAS (Microsoft Activation Scripts). Vui lòng chạy tập lệnh dưới quyền Administrator.

Lưu ý quan trọng:

- Tạm thời tắt phần mềm diệt virus nếu hệ thống nhầm lẫn file batch.

- Tất cả mã lệnh đều minh bạch, an toàn và chuẩn xác quốc tế.
