**MAS Pro Ultimate (ThanhDevHub-IT)** là trang web tiện ích giúp sinh viên IT và người dùng Windows quản lý, kiểm tra trạng thái bản quyền Windows/Office nhanh chóng, hỗ trợ tạo tự động các file kịch bản (`.bat`) chỉ với một cú click chuột.

## ✨ Tính Năng Nổi Bật

### 1. 🛡️ Kiểm Tra & Kích Hoạt Bản Quyền (Windows & Office)
- **Kiểm tra bản quyền nhanh:** Sao chép tức thì các lệnh quản trị hệ thống (`slmgr /xpr`, `cscript slmgr.vbs /dli`) để kiểm tra thời hạn kích hoạt hiện tại.
- **Bộ lọc thông minh theo nhu cầu:** Phân loại rõ ràng các phương thức dành riêng cho **Windows**, **Office**, hoặc **Tiện ích tạo Script**.
- **Tải trực tiếp File Batch (`.bat`):** Hỗ trợ xuất sẵn file kịch bản tự động cho từng phương thức.

### 2. ⚙️ Trình Tạo Custom Batch Script Trên Web
- Cho phép tùy chọn chế độ kích hoạt (**Windows HWID** hoặc **KMS38**), xem trước mã nguồn script trực tiếp và tải xuống file `.bat` tùy chỉnh.

### 3. 📊 Widget Thời Gian Thực & Thông Số Thiết Bị
- **Thời tiết & Vị trí (GPS / IP):** Tự động nhận diện vị trí và cập nhật nhiệt độ, tốc độ gió thực tế qua Open-Meteo API.
- **Nhận diện phần cứng & Trình duyệt:** Hiển thị hệ điều hành, trình duyệt đang dùng, độ phân giải màn hình và trạng thái kết nối mạng.
- **Giao diện linh hoạt:** Hỗ trợ chuyển đổi mượt mà giữa **Dark Mode / Light Mode** và song ngữ **Tiếng Việt / English**.
